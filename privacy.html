Privacy Policy

Last updated: 7 November 2026

Who uses this application

Personal Channel Tools is a private application used only by its owner to manage the owner's own YouTube channels. It is not offered to the public.

What data it accesses

With the owner's permission through Google OAuth, the application uses the YouTube API Services to:

  • upload the owner's videos and set their titles, descriptions, tags, thumbnails, playlists, category, language and scheduled publish times;
  • read the owner's channel and video information and YouTube Analytics reports for the owner's own channels.

How data is stored and shared

  • Data is stored only on the owner's own computer. Access tokens are stored encrypted.
  • Data is not sold, not shared with third parties, and not used for advertising.
  • The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

This application uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time from Google Account permissions. After access is revoked, locally stored data obtained from the API is deleted within 7 days.
